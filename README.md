## 快捷键与交互

| 操作 | 快捷键或方法 |
| --- | --- |
| 切换鼠标穿透 | **Ctrl+Alt+P** |
| 关闭游戏模式、恢复鼠标交互 | **F7** |
| 切换显示屏 | **F8** |
| 播放当前装备的第 1～5 个表情 | **Ctrl+Alt+1～5** |
| 展开表情 | 鼠标移入桌宠 |
| 固定展开／收起表情 | 点击底部计数 |
| 打开背包与设置 | 点击底栏右侧三横线，或双击托盘图标 |
| 打开无限开箱 | 点击底栏星形入口 |
| 拖动桌宠 | 按住角色拖动；禁用拖动、游戏模式或鼠标穿透时不可拖动 |
| 预览已拥有表情 | 在背包或图鉴中右键表情卡片 |
| 保存搭配 | 背包中点击空白预设位 |

若桌宠无法点击，先按 **F7** 关闭游戏模式，再用 **Ctrl+Alt+P** 切换鼠标穿透，或从系统托盘打开设置。

## 存档与升级

便携版存档位于 exe 旁的 `data/collection.json`，备份为 `collection.json.bak`。源码运行时在项目的 `data/`。

升级时先退出旧版，解压新 ZIP，再把旧版的整个 `data` 文件夹复制到新版 exe 旁。发行包不包含用户存档；上传仓库和 Release 不会带入个人收藏、账号或日志。

## 从源码运行与打包

需要 Windows x64 和 Node.js 24；首次安装依赖及 Electron 运行程序需要联网。

```powershell
npm ci
npm test
npm start
```

`npm ci` 的安装步骤会自动下载并校验所需 Electron 运行程序。生成便携目录：

```powershell
npm run build
```

输出位于 `dist/WuwaTappo-Offline-1.0.2/`。GitHub Actions 在 Windows 上自动安装依赖、运行测试、构建并压缩 ZIP。

## 验证与许可范围

`npm test` 验证初始收藏、资源完整性、抽取、合成、存档迁移、计数归零和装备表情选择。`npm run test:ui` 在独立存档中检查换装、输入、表情、置顶恢复、连续加载、筛选及保存，结果写入 `qa-output/result.json`；需要 Windows 桌面会话。

# Wuwa Tappo Offline Edition

Windows x64 个人离线桌宠。收藏、抽取、搭配和设置保存在本机；启动后不访问网络，也不连接官方账号。当前版本 **1.0.2**。

## 运行与构建

使用 Windows x64、Node.js 24。首次安装依赖需要联网：

```powershell
npm ci
npm test
npm start
```

制作便携版：

```powershell
npm run build
```

生成 `dist/WuwaTappo-Offline-1.0.2/`，运行其中的 `WuwaTappo-Offline.exe`。整个目录需要一起保留。GitHub Actions 会在提交后运行测试并构建 Windows 便携包，可在成功运行的 Artifacts 中下载。

## 功能

- 899 个收集物：260 个角色皮肤、135 个配件、504 个表情，内置 3098 张离线图像。
- 初始仅开放男女漂泊者经典形象、阿布配件和八个阿布基础表情，共 11 件。其余通过本地开箱或合成获得。
- 无限单抽/十连。普通 65%、珍稀 25%、稀有 9%、史诗 1%；十连至少珍稀，50 抽内史诗保底。
- 升阶合成消耗 10 份、平阶合成消耗 5 份同品类同稀有度的多余副本，可进行单次或十连合成，始终保留最后一份。
- 背包、预设、收藏、图鉴稀有度分组，7 个系列、55 个角色和稀有度组合筛选。
- 42 键紧凑键盘放在原有底部胶囊内，右斜 30°、圆润字体、轻微立体效果。键盘和鼠标输入同步拍桌与计数。
- **999 再增加一次归零**，从当前装备的表情中随机浮现一个；未装备表情时只归零。按住同一按键不会重复计数。
- 表情使用原始互动图像，侧边按钮沿用原版透明气泡边框和 32/30 像素布局；浮现沿用原版 80 像素、1 秒上浮轨迹，保留扇形展开及按压弹性。
- 鼠标移入桌宠展开表情，移出收起；点击计数可固定展开/收起；Ctrl+Alt+1～5 播放已装备表情。
- 桌宠始终置顶，失焦或窗口层级变化后自动恢复，不主动抢输入焦点。系统安全桌面和独占全屏由 Windows 管理。
- 拖动、大小、透明度、悬停半透明、鼠标穿透、多显示器和可选开机启动。

## 快捷键与存档

| 操作 | 快捷键 |
| --- | --- |
| 鼠标穿透开关 | Ctrl+Alt+P |
| 关闭游戏模式 | F7 |
| 切换显示屏 | F8 |
| 播放已装备表情 | Ctrl+Alt+1～5 |

便携版存档在 exe 旁的 `data/collection.json`，备份为 `collection.json.bak`。源码运行时在项目的 `data/`。升级前退出旧版，将原来的 `data` 文件夹保留或复制到新版 exe 旁；不要用压缩包中的文件替换自己的存档。发行包不含任何用户存档。

## 验证

`npm test` 覆盖资源完整性、初始收藏、抽取、合成、迁移、999 归零、装备表情选择和始终置顶设置。

`npm run test:ui` 启动隔离存档的 Electron 回归测试，检查换装、输入、表情、置顶恢复、260/504 个条目连续加载、筛选及保存。结果在 `qa-output/result.json`；真实存档不受影响。需要 Windows 桌面会话。
